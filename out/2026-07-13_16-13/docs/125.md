### De ce este considerată media aritmetică 'cel mai bun' indicator al tendinței centrale?
Answer: În general, media aritmetică nu este considerată "cel mai bun" indicator al tendinței centrale într-o distribuție statistică, ci doar unul dintre metodele cele mai comune și simple de calculare a acesteia. Acest lucru se poate deduce din faptul că articolul Wikipedia despre statistica descoperă alte metode de estimare a centrului unei distribuții, cum ar fi mediana și moda. De exemplu, cităm: "Există diverse metode de a estima centrul unei distribuții, printre care mediană, modă și medie aritmetică." ("Statistica", Wikipedia).

### Cum se calculează media aritmetică în practică?
Answer: În practica calculului mediei aritmice, aceasta se obține prin împărțirea sumei tuturor valorilor individuale dintr-un set de date la numărul total de valori respective. De pildă, dacă avem urmatoarele valori: 2, 3, 5, 7 și 11, atunci media aritică poate fi calculată astfel: [(2 + 3 + 5 + 7 + 11)/5] = 28/5 = 5,6. Acest lucru este menționat și pe Wikipedia, unde se spune că "media armonică" este o măsură centrală care reprezintă suma totale a valorilor unui ansamblu de date împărțită la numărul de elemente din acel ansamblu." ("Grosimetric average", citat după https://ro.wikipedia.org/wiki/Medie_arithmetică).
